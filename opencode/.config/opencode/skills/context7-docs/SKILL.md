## When to use

Load this skill when you need accurate, current documentation for a library, framework, or API (React, Next.js, Playwright, etc.).

## What to do

1. Prefer Context7 tools over inventing APIs from memory.
2. Resolve the correct library, then fetch docs relevant to the user's question.
3. Cite the version or library name when it matters for the answer.
4. If Context7 is unavailable, say so and fall back to web search or local code — do not fabricate APIs.
